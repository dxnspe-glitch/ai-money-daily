# 流水线架构骨架

> 本文只描述模块级架构与数据流，用于说明这套系统的运行方式。商机洞察的方法论细节不在本文范围。

## 总览

```
┌─────────────┐    ┌──────────────┐    ┌───────────────────┐
│ 公开资讯源   │ →  │ 日报生成脚本  │ →  │ HTML 仪表盘        │
│ (公开 API)  │    │ (Python)     │    │ + JSON 摘要        │
└─────────────┘    └──────────────┘    └─────────┬─────────┘
                                                  │
                                          ┌───────▼────────┐
                                          │ 商机洞察加工     │
                                          │ (AI Agent 加工) │
                                          └───────┬────────┘
                                                  │
                    ┌─────────────┬───────────────┼─────────────┐
                    ▼             ▼               ▼             ▼
              微信推送摘要    官网归档(重发布)   本仓库归档     公众号素材
```

## 模块职责

| 模块 | 职责 | 运行频率 |
|---|---|---|
| 数据抓取 | 拉取公开资讯源的当日精选条目（标题/来源/链接/摘要） | 每日 09:00 |
| 日报生成 | 按 5 个版块渲染单文件 HTML 仪表盘，输出 JSON 摘要；当日无数据自动回退最近一期 | 随抓取 |
| 商机洞察 | AI Agent 基于当日信号加工"生意机会 + 避坑"内容（方法论不在本文范围） | 随生成 |
| 多渠道分发 | 微信纯文字摘要 / 官网归档重发布 / GitHub 归档 / 公众号素材 | 随生成 |

## 设计要点

- **单文件自包含**：HTML 全部内联，微信内可直接打开
- **回退机制**：当日数据不足时回退最近一期并在输出中标注，推送不断档
- **失败告警**：任何环节失败在推送尾部追加告警标记，不静默失败
- **链接稳定**：官网与归档对外分享链接不变，内容每日更新
- **合规**：仅聚合元数据与链接，每条附原文出处，不复制正文

## 技术栈

Python 3.11+ / AI Agent 定时调度 / 静态托管 / Git 归档。无需服务器与数据库。
