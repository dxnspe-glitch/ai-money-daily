# AI 搞钱早班车 · ai-money-daily

> 每天 9 点自动生成的 AI 日报 —— **大事速览 · 3 条生意机会 · 1 条避坑提示**

每天早上 9:00，一条自动化流水线实时抓取公开 AI 资讯、加工成一份单页可读的日报，并归档到本仓库 `archive/` 目录。

## 每期包含

- **⚡ AI 圈大事速览** —— 模型 / 产品 / 行业 / 论文 / 观点，5 个版块精选，每条附原文出处
- **💰 3 条生意机会** —— 从当日动态挖出"普通人能上手"的机会：切入方式、客户、成本、第一周动作
- **🛡️ 1 条避坑提示** —— 套路、泡沫与骗局识别

## 本仓库包含什么

- `archive/` —— 每日日报完整版（HTML），自动归档
- `docs/architecture.md` —— 流水线架构骨架（模块级说明）

**本仓库只包含架构骨架与公开归档。** 日报背后的商机洞察方法论、筛选标准与 Prompt 体系不在本仓库中。
